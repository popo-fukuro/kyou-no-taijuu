# きょうの体重

今日の体重を1つ入れるだけで、ここ2週間の「増えた・減った」が折れ線グラフでひと目でわかる体重記録アプリです。登録もインストールもいりません。

👉 **今すぐ使う：https://popo-fukuro.github.io/kyou-no-taijuu/**

## こんな人に
- 体重は測っているけど、メモがバラバラで「減ってるのかどうか」が見えない人
- アプリの登録やインストールはめんどう。でも記録は続けたい人
- 細かい分析より、「ここ2週間でどうなった？」だけをさっと知りたい人

## 使い方
1. ページを開いて、今日の体重を入れる（例：62.4）
2. 「記録」を押す（Enter キーでもOK）
3. ここ2週間の折れ線グラフが伸びて、「10/1から 0.8kg 減」のように増減が出ます。グラフの点をタップすると、その日の体重と前回との差が見られます

- 記録できるのは今日の分だけです（1日1件）。同じ日に入れ直すと上書きされます
- 「記録の一覧」を開くと、これまでの記録と前回との差を一覧で見られます

## データについて
入力したデータは、あなたの端末（ブラウザ）の中だけに保存されます。どこにも送信されません。
（ブラウザのデータを消すと、記録も消えます）

- 別の端末や別のブラウザとは、記録は共有されません
- 記録の書き出し（バックアップ）の機能はありません
- ページを置いている GitHub が、アクセスの記録（IPアドレスなど）を保存します

## ご注意
- このアプリは体重を記録して見るための道具で、医療・ダイエットの助言をするものではありません。体調や減量のことは、医師などの専門家にご相談ください
- 共用の端末で使うと、記録が他の人にも見えます
- 記録はお使いのブラウザの中だけに保存されます。ブラウザのデータ削除や端末の変更、長いあいだ開かなかった場合などに消えることがあります
- このアプリは無保証で提供しており、記録が消えたことなどによる損害には責任を負えません
